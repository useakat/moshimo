## 背景・動機

「もしも〜だったら」を科学的知見に基づいて描き、note 記事と Web アプリで公開するプロジェクトを立ち上げるため、運用方針・計画・ブランドを文書化する必要があった。

## 実施内容

- `CLAUDE.md`（運用ルール）、`plan.md`（計画）、`brand.md`（ブランドガイド）を作成
- 方針を確定：
  - 読者は科学に詳しくない大人全般
  - 当面の分野は宇宙・物理
  - 出典は巻末にまとめる
  - 公開は note 先行、のちに Web アプリ化
- 帰結の導出で、一次情報だけでは足りない情報は数値計算で補う（記事への概算の添付は必須としない）
- プロジェクト名は「もしもプロジェクト」

## 変更ファイル

| ファイル | 変更内容 |
|---|---|
| `CLAUDE.md` | 目的・構成・役割・コンテンツ制作の原則・禁止事項を記述 |
| `plan.md` | フェーズ、記事制作フロー、テーマ選定基準、未決事項を記述 |
| `brand.md` | ミッション、読者像、トーン、記事構成、文体ルールを記述 |

## 確認結果

3 ファイルの内容を、ユーザーと対話しながら確認・修正した。
