「もしも〜だったら」という仮想世界を、できるだけ科学的知見に基づいて構築し、note 記事と Web アプリとして公開するプロジェクトです。
もしもの世界を通して、この世界の不思議やすごさに気づいてもらい、日々の生活に「常識がひっくり返る驚き」と楽しみを届けることを目指しています。

- 想定読者：科学に詳しくない大人全般
- 公開先：note（先行）→ Web アプリ
- 当面の分野：宇宙・物理
