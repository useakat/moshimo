## 0. 方針 2 で動く量と、文献の変数との対応

方針 2 で動く真のパラメーターは α（1/k）だけ。x ≡ Λ_QCD/(m_e c²)（α_s の代わり）、α_G、y（質量比）、λ、混合角などは不変。したがって m_q/Λ_QCD も不変。

文献が動かしている変数は多くの場合これと一致しないので、換算が必要：

| 文献の変数 | 方針 2 への対応 | 注意 |
|---|---|---|
| α | そのまま。Δα/α = −Δc/c | |
| 軽クォーク質量 m_q（Λ_QCD 固定）、m_q/Λ_QCD | 方針 2 では m_q/Λ_QCD が不変（x 固定）なので、これらに対する段は効かない | **参考**：方針 1 では Λ_QCD が α_s に指数関数的に敏感で（ΔΛ_QCD/Λ_QCD ≈ 7〜8 × Δα_s/α_s。α_s(M_Z) = 0.118、b₀ = 7 で概算。確度：低）、換算が不安定だった。不採用の理由の一つ |
| 「核力の強さ」「α_s」（Davies 1972、MacDonald & Mullan 2009 など、QCD 以前または現象論的な結合） | 方針 2 では不変なので、これらの段は効かない（文献値の整理として 1-1 節に残す） | |
| ヒッグス v（クォーク質量に比例） | 方針 2 では m_q/Λ_QCD が不変なので、v の変化に対する段（v/v₀ ≳ 2 など）は効かない | |
| 重力：α_G = Gm_p²/(ħc)（文献は m_p 基準が多い） | 方針 2 では α_G（電子基準）が不変なので、重力の段は置かない。m_p/m_e も不変（x 固定） | |

**方針 2 での帰結**：強い力・核物理に関する段（1-1 節、1-2 節の m_q 経由の行）は、m_q/Λ_QCD が不変なので効かない。効くのは α の段（1-2 節の α 経由の行、1-3 節）だけで、はしごは α だけで作る（1-7 節）。

### 1-6. 原子・原子核・核子の「存在」条件（ノートブック確認 2026-11-06、logs/ladder_q8_atoms_nuclei.log）
「原子ができるか」「原子核ができるか」を直接扱った文献の有無を確認した。結論：**α の上限と、核力を数十%動かした場合の原子核の崩壊は文献がある。α を桁で小さくした場合（方針 2 の k = 1000）を扱った文献はない（α_s を桁で小さくした場合もない。方針 1 で必要だった）。**

| 観点 | 文献の条件 | 方針 2 での読み | 出典 |
|---|---|---|---|
| 原子（上限） | α < 0.2（対生成）、α < 1/94（多体系の数学的安定、Lieb & Yau 1991）、α < √2（p → H + e⁺） | すべて上限。α が小さくなる方向には抵触しない | Barnes 2012、Adams 2019、Trialogue |
| 原子（下限） | **孤立した原子については下限を与える文献なし**（非相対論の水素は α > 0 なら必ず束縛。束縛エネルギー m_e c² α²/2）。Adams 2019 が GUT 整合性から α > 1/180 を挙げるが、方針 2 とは前提が異なる | 水素原子は「陽子が存在すれば」できる。原子単位系では水素原子の大きさ・エネルギーは定義上不変 | Barnes 2012、Adams 2019 |
| 原子の大きさ ≫ 原子核の大きさ | α(m_e/m_p)/α_s < 1/1000（Barrow & Tipler） | 方針 2 では α_s と m_e/m_p が不変で α だけ小さくなるので、αβ/α_s は小さくなり、この上限型の条件は満たされる | Barnes 2012 |
| 化学のエネルギー ≪ 核反応のエネルギー | α²(m_e/m_p)/α_s² < 1/1000（Barrow & Tipler） | 同上 | Barnes 2012 |
| 水の性質・有機化学 | α ≳ 0.08 で水の性質が激変（上限のみ） | 抵触しない | Barnes 2012 |
| 惑星の居住性 | α⁻¹ = 145 ± 50（核融合の終点が鉄）、145 ± 9（地球内部の放射性発熱。Sandora 2016） | 方針 2 では α だけが動くのでそのまま使える（要精読）。1-7 節に採用 | Adams 2019 経由 |
| 原子核（核力を弱める） | 核力 −9% で重水素が非束縛（Davies 1972）。m_u + m_d を +64% で重い核が全般に崩壊（中心ポテンシャルが弱すぎる。95% CL） | 方針 2 では m_q/Λ_QCD が不変なので効かない（1-1 節の段） | Barnes 2012、Damour & Donoghue 2008 |
| 核子（Λ_QCD ≪ m_q） | **扱った文献なし。** 文献が扱うのは m_q/Λ_QCD の数十%までの変化。α_s → 0 を独立の事例として扱ったソースもない（weakless universe のような「strongless universe」は存在しない） | 方針 2 では x が不変なので、この領域には入らない | — |
| α → 0 の極限 | 事例研究はない。式のレベルでは、電磁自己エネルギーが消えて m_n − m_p = Z₀(m_d − m_u) > 0（陽子は安定のまま）、原子核のクーロン障壁が消える | 方針 2 の k = 1000（α → 0 に近い側）で「陽子は崩壊しない（m_n − m_p が増える）」「クーロン反発が弱まる」の根拠に使える | Damour & Donoghue 2008、Uzan 2011 |

補足（推測、文献なし。方針 1 の場合のみ。不採用）：方針 1 の k = 1000 では原子単位で α_s ≈ 1.2×10⁻⁴ となり、閉じ込めスケール Λ_QCD はクォーク質量より桁違いに小さくなる。クォークは「弱い色クーロン力」で緩く束縛される粒子になり、今の陽子（質量の 99% が束縛エネルギー）とは別物になる。この描像は摂動論的な直感であり、記事では「今の陽子・原子核は存在しない」以上のことは断定しない。

### 1-7. 方針 2 のはしご（α だけ動く世界。暫定。2026-11-13 追記）
方針 1 は、結果が「SI で何を固定するか」という約束事（場の規格化・次元の割り当て）に左右されるため、採用しない（理由は `themes/001-…md` の §5）。方針 2 に絞る。1-1〜1-6 の方針 1 向けの換算（α_s の ×7.6 など）は、この節では使わない。

**定義**：独立な 27 個の無次元パラメーターのうち α だけを α → α/k（原子単位系で c_au → k·c_au）とし、ほかの 26 個は不変とする。基底は次のとおり。
- 不変：x ≡ Λ_QCD/(m_e c²)（α_s の代わり）、sin²θ_W、y（m_f/m_e）、λ、混合角（8）、θ_QCD、α_G = G m_e²/(ħc)、Λa₀²
- 導出量として動く：v/E_h ∝ k²、Λ_au ∝ k²、M_W・M_Z（m_e c² に対して ∝ √α）など
- 換算：c/c₀ = α₀/α（Δα/α = −Δc/c）。「α_s(μ) の関数形は J で不変」という近似（QED の補正は無視）

はしご（c/c₀ の変化。壊れる順）：

| 光速の上限側（α が小さくなる） | c/c₀ | 根拠 |
|---|---|---|
| 炭素・酸素ができない | +2.6%（約 3%） | ホイル状態 ±100 keV ↔ α ±2.5%（Epelbaum ら 2013） |

| 核融合の終点が鉄でなくなる | +42%（α⁻¹ ≤ 195） | Sandora 2016（**要精読**） |
| 恒星が光らない | ×100（α ≥ α₀/100） | Adams 2008 |

|---|---|---|
| 地球内部の放射性発熱が続かない | −0.8%（約 −1%。α⁻¹ ≥ 136） | Sandora 2016（**要精読・地球固有**。今の α⁻¹ = 137.04 が下端の 0.8% 内側） |

| 多体系が確実に不安定 | −99.7%（α > 128/(15π) ≈ 2.72） | Lieb & Yau 1991（ResearchGate の引用経由） |

読み取り：
- 光速が速い側で最も厳しいのは炭素・酸素（約 3%）。光速を 1000 倍にすると α が α₀/1000 になり、恒星の下限（α₀/100）を 10 分の 1 下回る。「1000 倍は論外」の山場は方針 2 でも残る。
- 孤立した原子の存在に、α の下限はない（1-6 節）。α が小さい側の制限は、恒星の核燃焼・ホイル状態・上表の 2 つの Sandora 条件に限られる。

**使わない・使いにくいもの**：
- 12C(α,γ)16O の S 因子 0.02%（生存条件ではなく感度の指標）
- Ekström ら 2010 の Δα/α ~ 10⁻⁵（C/O 共存。核力との結びつけがモデル依存で、方針 2 に直接は当てはまらない）
- Lieb & Yau の α < 1/94（数学的に証明できる十分条件で、物理的な制限ではない）
- 水の性質が変わる α ≳ 0.08（影響の予測は難しいという記述で、明確な制限ではない）
- αβ/α_s、α²β/α_s² の条件（α_s の意味が曖昧で、数値化していない）
- Adams 2019 の α > 1/180（大統一理論の整合性という別の前提）

**未確認・要精読**：
- 文献ごとに、α 以外に何を固定したか（Adams 2008 は G も動かしている）。表の値を α のみの変化にそのまま当てはめてよいかは未確認。
- Sandora 2016 の 2 条件の仕組み。1 つ目は恒星の核合成、2 つ目は地球固有の条件。ソースには結論の範囲と 1 文の説明だけがある。
- 上表の「概算」2 行（−60%、−96.9%）は、一次情報で係数を確認する。
- BBN への α 経由の影響（Q_np = m_n − m_p の変化）は未調査。上のはしごに BBN の段は入っていない。

## 2. k = 1000 の場合の帰結（方針 2）
真のパラメーターの値：α = 7.3×10⁻⁶（c = 137,036 原子単位）。x（= Λ_QCD/(m_e c²)）、α_s、α_G、Λa₀²、y、λ などは現在の値のまま。導出量として、原子単位での Λ_QCD が 10⁶ 倍、G_au が 1000 倍になる。

| 領域 | 帰結 | 確度 | 根拠 |
|---|---|---|---|
| 原子・化学 | 原子の大きさとエネルギー準位は原子単位で不変。相対論的補正 ∝ α² が 10⁻⁶ 倍：金は銀色、水銀は固体、鉛蓄電池の電圧は約 0.3〜0.4 V、微細構造・スピン軌道相互作用が消える | 中（文献の相対論的効果の値から） | Pyykkö 2012、Ahuja ら 2011、Calvo ら 2013、APS Physics 2017 |
| 光と放射 | 原子の時計で光は 1000 倍速い。同じエネルギーの光の波長は 1000 倍。自発放出が 10⁻⁹ 倍で励起状態の寿命 10⁹ 倍。同じ温度の熱放射 σ ∝ α² が 10⁻⁶ 倍。トムソン散乱 10⁻¹² 倍 | 中（原子単位のスケーリング） | themes §6 |
| 磁気 | 電流の作る磁気の力 ∝ α²（μ₀ ∝ 1/c²）が 10⁻⁶ 倍。磁石・モーター・発電機が実質的に働かない | 中 | themes §6 |
| 静止エネルギー | E = mc² が原子のエネルギーに対して 10⁶ 倍。対生成・対消滅のエネルギーは 10⁶ 倍遠くなる | 高 | 定義 |
| 強い力・原子核・核子 | 不変（x 固定）。m_p/m_e、核力、原子核の結合エネルギーは今のまま。核内のクーロン反発（QCD のスケールに対して ∝ α）は 1/1000 になり、重い原子核は安定に近づく（影響は未計算） | 中（スケーリング）／低（核の安定性への効果は未計算） | themes §6 |
| 恒星 | α = α₀/1000 は、Adams 2008 の下限（α ≳ α₀/100）を 10 分の 1 下回る。文献によれば、安定な核燃焼をする恒星は存在しない。ただし、Adams 2008 が α 以外に何を固定した値かは未確認（要精読）。ガモフエネルギー ∝ α² は 10⁻⁶ 倍 | 中（文献値の適用範囲は要確認） | Adams 2008 |
| 中性子と陽子の質量差・BBN | m_n − m_p が約 1.3 MeV → 約 2.6 MeV（概算）。BBN への影響は未調査 | 低 | Hogan（Barnes 2012 経由）。未調査 |
| 弱い力 | 低エネルギーでは不変（G_F m_e² は y_e だけで決まる）。W、Z は電子に対して 1/√1000 の質量 | 高 | themes §4 |
| 重力 | α_G は不変。原子の力に対する重力は G_au ∝ 1000 倍 | 高 | themes §6 |
| 宇宙定数 | Λa₀² は不変 | 高 | 定義 |

結論：方針 2 の 1000 倍世界では、原子・原子核・化学は（相対論的な変化を除いて）今のままだが、安定な核燃焼の恒星は存在しない（文献値の適用範囲は要確認）。「世界が壊れずにいられる」光速の幅は、1-7 節のはしごのとおり約 3% 以内（炭素・酸素）。
