## 0. 方針 1 で動く量と、文献の変数との対応

方針 1 で動く真のパラメーター：α（1/k）、α_s（1/k）、α_G（1/k⁵）。クォーク質量 m_q、ユカワ結合、v は固定。

文献が動かしている変数は多くの場合これと一致しないので、換算が必要：

| 文献の変数 | 方針 1 への換算 | 注意 |
|---|---|---|
| α | そのまま。Δα/α = −Δc/c | |
| 軽クォーク質量 m_q（Λ_QCD 固定） | 核物理を決めるのは比 m_q/Λ_QCD。方針 1 は m_q 固定で Λ_QCD が動くので、「m_q を +x%」≒「Λ_QCD を −x%」 | Λ_QCD ∝ μ·exp(−2π/(b₀α_s(μ))) なので、ΔΛ_QCD/Λ_QCD ≈ (2π/(b₀α_s))·Δα_s/α_s ≈ **7〜8 × Δα_s/α_s**（α_s(M_Z) = 0.118、b₀ = 7 で概算。確度：低。要検証） |
| 「核力の強さ」「α_s」（Davies 1972、MacDonald & Mullan 2009 など、QCD 以前または現象論的な結合） | 核力の有効的な強さ。QCD の α_s(M_Z) とは別物。m_q/Λ_QCD の変化に直すには Damour & Donoghue の G_S の対応を使う | 確度：中〜低 |
| ヒッグス v（クォーク質量に比例） | 方針 1 では v 固定。m_q/Λ_QCD の変化として読み替える | |
| 重力：α_G = Gm_p²/(ħc)（文献は m_p 基準が多い） | 方針 1 の α_G（電子基準）は 1/k⁵。m_p/m_e は「推測扱い」だが、はしご（数%の範囲）では不変とみなす | |

**重要な帰結（確度：低、要検証）**：Λ_QCD は α_s に指数関数的に敏感なので、核物理の許容幅（m_q/Λ_QCD で数%〜数十%）は、α_s では 1/7〜1/8 に縮み、c の許容幅はさらに狭くなる。

### 1-6. 原子・原子核・核子の「存在」条件（ノートブック確認 2026-11-06、logs/ladder_q8_atoms_nuclei.log）
「原子ができるか」「原子核ができるか」を直接扱った文献の有無を確認した。結論：**α の上限と、核力を数十%動かした場合の原子核の崩壊は文献がある。α や α_s を桁で小さくした場合（方針 1 の k = 1000）を扱った文献はない。**

| 観点 | 文献の条件 | 方針 1 での読み | 出典 |

| 原子（下限） | **孤立した原子については下限を与える文献なし**（非相対論の水素は α > 0 なら必ず束縛。束縛エネルギー m_e c² α²/2）。Adams 2019 が GUT 整合性から α > 1/180 を挙げるが、方針 1 とは前提が異なる | 水素原子は「陽子が存在すれば」できる。原子単位系では水素原子の大きさ・エネルギーは定義上不変 | Barnes 2012、Adams 2019 |
| 原子の大きさ ≫ 原子核の大きさ | α(m_e/m_p)/α_s < 1/1000（Barrow & Tipler） | α と α_s が同率で 1/k なので比は不変。ただし m_e/m_p は核子質量が計算不能なため評価できない | Barnes 2012 |
| 化学のエネルギー ≪ 核反応のエネルギー | α²(m_e/m_p)/α_s² < 1/1000（Barrow & Tipler） | 同上 | Barnes 2012 |
| 水の性質・有機化学 | α ≳ 0.08 で水の性質が激変（上限のみ） | 抵触しない | Barnes 2012 |
| 惑星の居住性 | α⁻¹ = 145 ± 50（核融合の終点が鉄）、145 ± 9（地球内部の放射性発熱。Sandora 2016） | 方針 1 では α と一緒に α_s も動くので、そのままは使えない。参考値 | Adams 2019 経由 |
| 原子核（核力を弱める） | 核力 −9% で重水素が非束縛（Davies 1972）。m_u + m_d を +64% で重い核が全般に崩壊（中心ポテンシャルが弱すぎる。95% CL） | 1-1 節の段と同じ。数%〜数十%の範囲 | Barnes 2012、Damour & Donoghue 2008 |
| 核子（Λ_QCD ≪ m_q） | **扱った文献なし。** 文献が扱うのは m_q/Λ_QCD の数十%までの変化。α_s → 0 を独立の事例として扱ったソースもない（weakless universe のような「strongless universe」は存在しない） | 計画どおり、数値を出さず「今の陽子・原子核は存在しない」と定性的な推測で書く | — |
| α → 0 の極限 | 事例研究はない。式のレベルでは、電磁自己エネルギーが消えて m_n − m_p = Z₀(m_d − m_u) > 0（陽子は安定のまま）、原子核のクーロン障壁が消える | 方針 1 の k = 1000 で「陽子は（存在すれば）崩壊しない」「クーロン反発が消える」の根拠に使える | Damour & Donoghue 2008、Uzan 2011 |

補足（推測、文献なし）：方針 1 の k = 1000 では原子単位で α_s ≈ 1.2×10⁻⁴ となり、閉じ込めスケール Λ_QCD はクォーク質量より桁違いに小さくなる。クォークは「弱い色クーロン力」で緩く束縛される粒子になり、今の陽子（質量の 99% が束縛エネルギー）とは別物になる。この描像は摂動論的な直感であり、記事では「今の陽子・原子核は存在しない」以上のことは断定しない。

## 2. k = 1000 の極端な場合の帰結（方針 1）
真のパラメーターの値：α = 7.3×10⁻⁶（c = 137,036 原子単位）、α_s ≈ 1.2×10⁻⁴、α_G ≈ 6×10⁻⁵⁴（電子基準で 1/k⁵）、G_F m_e² 不変、Λ_au 10¹² 倍。

| 領域 | 帰結 | 確度 | 根拠 |
|---|---|---|---|
| 強い力・原子核 | Λ_QCD ∝ exp(−2π/(b₀α_s)) が事実上ゼロ。クォークを閉じ込める力が原子の尺度で消え、今の陽子・中性子・原子核は存在しない。クォークは弱いクーロン型の色の力で緩く結びつくだけ | 低（定性的推測。数値は出さない） | Λ_QCD の α_s 依存（Uzan 2011 ほか） |
| 恒星 | 核子がないので核融合は起きない。仮に核子があっても α は Adams 2008 の下限 α₀/100 を 10 倍下回り、核燃焼する恒星は存在しない。α_G が 10⁻¹⁵ 倍なので恒星の質量スケール M₀ ∝ α_G^{−3/2} は 10^{22.5} 倍 | 中（α の下限は文献値）／低（α_G の換算） | Adams 2008 |
| 原子・化学（仮に核子があれば） | 原子の大きさとエネルギー準位は原子単位で不変。相対論的補正 ∝ α² が 10⁻⁶ 倍：金は銀色、水銀は固体、鉛蓄電池の電圧は約 0.3〜0.4 V、微細構造・スピン軌道相互作用が消える | 中（文献の相対論的効果の値から） | Pyykkö 2012、Ahuja ら 2011、Calvo ら 2013、APS Physics 2017 |
| 光と放射 | 原子の時計で光は 1000 倍速い。同じエネルギーの光の波長は 1000 倍。自発放出が 10⁻⁹ 倍で励起状態の寿命 10⁹ 倍。同じ温度の熱放射 σ ∝ α² が 10⁻⁶ 倍。トムソン散乱 10⁻¹² 倍 | 中（原子単位のスケーリング） | themes ファイル §5 |
| 磁気 | 電流の作る磁気の力 ∝ α²（μ₀ ∝ 1/c²）が 10⁻⁶ 倍。磁石・モーター・発電機が実質的に働かない | 中 | themes ファイル §5 |
| 静止エネルギー | E = mc² が原子のエネルギーに対して 10⁶ 倍。対生成・対消滅のエネルギーは 10⁶ 倍遠くなる | 高 | 定義 |
| 重力 | 原子の力に対して 10⁻¹² 倍（G_au）。物体の自重でつぶれる限界質量（惑星・小惑星の上限 ∝ α_G^{−3/2}）が 10^{22.5} 倍 | 中〜低 | Carr & Rees 型のスケーリング（Tegmark 2006、Barnes 2012） |
| 弱い力 | 低エネルギーでは不変（G_F m_e²）。W、Z は電子に対して 1/√1000 の質量 | 高 | themes ファイル §4 |
| 宇宙定数 | 原子の尺度で 10¹² 倍だが、依然 10⁻⁶¹。効かない | 高 | 定義 |

結論：方針 1 の 1000 倍世界には原子核も恒星も化学もない。「世界が存在する」ための c の許容幅は、1-x 節のはしごのとおり ±1% 未満。
