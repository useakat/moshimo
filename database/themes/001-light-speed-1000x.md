## 1. 問いと狙い
「もしも光速が今の 1000 倍だったら、宇宙・太陽系・地球はどうなるか」。
元の動機は「一番近い恒星（アルファ・ケンタウリ、約 4.4 光年）まで 1 日ほどで行ける世界」で、移動時間を 1/1000 にする光速として 1000 倍を選んだ。
記事の核心は、**「光速の値そのものに意味はなく、意味があるのは比だけ」**という事実と、それを認めた上で「光速を変える」とは何を変えることなのかを、読者が追えるように示すこと。

## 2. 基本理論と基本パラメーター

### 基本理論
ニュートリノ質量ありの素粒子標準模型 + 一般相対性理論（宇宙定数つき）。理論は変えず、パラメーターの値だけを変える。

### SI での基本パラメーター（31 個）
| 種類 | パラメーター | 個数 |
|---|---|---|
| 単位の約束に近い定数 | c、ħ、ε₀ | 3 |
| ゲージ結合 | g（SU(2)）、g'（U(1)_Y）、g_s（SU(3)） | 3 |
| ユカワ結合 y | 荷電レプトン 3、クォーク 6、ニュートリノ 3 | 12 |
| ヒッグス | λ（自己結合）、v（真空期待値） | 2 |
| 混合角 | CKM（3 角 + 1 位相）、PMNS（3 角 + 1 位相） | 8 |
| その他 | θ_QCD、Λ（宇宙定数）、G | 3 |
| 合計 | | 31 |

約束事：
- g、g'、g_s の SI 値は e と同じ流儀（α_i = g_i²/(4πε₀ħc)）で定義した場合の数え方。**これは SI 流の約束事**で、標準模型の標準的な書き方では g_s は無次元（g_s² = 4πα_s）。場の再定義や次元の割り当てで値の「置き場所」が変わりうる（§5）
- e = g sinθ_W、1/e² = 1/g² + 1/g'² は関係式で、e は導出量
- ニュートリノがマヨラナ粒子なら位相が 2 つ増える（記事には影響しない）

### 導出量（基本パラメーターではないもの）
- 素粒子の質量：m_f = y_f v/√2、m_W = gv/2、m_Z = m_W/cosθ_W、m_H² = 2λv²（木のレベル）
- Λ_QCD：質量（エネルギー）の次元を持つ導出量。QCD のランニングを指定する量（1 ループで Λ_QCD = μ·exp(−2π/(b₀α_s(μ)))）。Λ_QCD の値そのものは QCD の理論から決まらず、標準模型の入力パラメーター（α_s の値を 1 点で与えることと同じ）
- 核子（陽子・中性子）の質量：質量の約 99% は QCD の結合エネルギーで、Λ_QCD と軽クォーク質量から決まる
- フェルミ定数：G_F = 1/(√2 v²)
- 核力、原子核の結合エネルギー、化学結合など

## 3. 真のパラメーター（27 個）
単位は kg、m、s、A の 4 つ。次元つきの量 9 個（c、ħ、ε₀、g、g'、g_s、v、Λ、G）のうち 4 個分は単位の取り替えで住人には見えず、残る **5 個の無次元量**に、最初から無次元の 22 個（y 12、λ 1、混合角 8、θ_QCD 1）を加えた **27 個の独立な無次元量**の値の組が世界を一意に決める。次元つき定数（c、ħ、G など）の個別の値には物理的意味がない（Duff–Okun–Veneziano の議論）。

27 個の選び方（基底）は一意ではない。単位系を 1 つ選ぶと、その単位での数値の組が自然な基底になる。

文献の許容幅との照合に使う。原子単位系との変換：α = 1/c、α_W = 1/(c·sin²θ_W)、α_G = G_au/c、v/(m_e c²) = v_au/c²、Λλ_C² = Λ_au/c²（λ_C = ħ/(m_e c)）。

## 4. 方針 2（採用）：α だけが動く世界

### 定義
**独立な 27 個の無次元パラメーターのうち α だけを α → α/k（原子単位系で c_au → k·c_au）とし、ほかの 26 個は不変とする。** 極端な例として k = 1000 を使う。

無次元量で直接指定するので、単位系や場の規格化の取り方に依存しない。

### 基底の指定
| パラメーター | 変化 | 備考 |
|---|---|---|
| α | × 1/k | 唯一動くパラメーター |
| sin²θ_W | 不変 | α_W = α/sin²θ_W は 1/k になる（導出量） |
| x ≡ Λ_QCD/(m_e c²) | 不変 | α_s の代わりに基底に取る。核物理・ハドロンの質量比を不変にする条件（下記） |
| y（12、質量比 m_f/m_e） | 不変 | |
| λ、混合角（8）、θ_QCD | 不変 | |
| α_G = G m_e²/(ħc) | 不変 | G_au = α_G/α は k 倍 |
| Λa₀² | 不変 | |

### α_s の代わりに x を取る理由
- x と α_s(M_Z) は、ほかの 26 個を固定すると一対一に対応する（1 ループ・概算）：x = [M_Z/(m_e c²)]·exp(−2π/(b₀α_s(M_Z)))、M_Z/(m_e c²) = √(4πα)/(√2·y_e·sinθ_W cosθ_W)。独立な数は 27 個のまま。
- 「α_s をどの基準スケールで固定するか」は、Λ_QCD を他のどの質量に対して固定するかと同じ問い。M_Z を基準にすると、M_Z が g を含んで α と共に動くため不自然。ハートリーエネルギーも電磁気のスケールなので不自然。フェルミオン質量（m_e c² = y_e v/√2 など、J で固定）に結びつけるのが自然。
- x を固定することは、α_s(μ) の関数形（μ を J で測る）を変えない、ということと同じ。核物理に効く m_q c²/Λ_QCD = (y_q/y_e)/x が不変になる。
- 無次元の比 Λ_QCD/(m_q c²) は、α を動かしても Λ_QCD(J) と m_q c²(J) が不変なので不変。原子単位系で書くと、Λ_au = Λ_QCD/E_h が k² 倍になるが、(Λ_au/m_q,au)·α² として打ち消し合う（α_au = α、c_au = 1/α）。

### 近似・仮定
- **QCD と QED の切り離し**：標準模型では α と Λ_QCD（α_s）は別々の入力パラメーター。QED が α_s のランニングに与える影響（α/π 程度の高次の補正）は無視する。大統一理論のように α と α_s を結びつけるモデルは扱わない。
- ハドロンの質量への電磁補正（陽子と中性子の質量差など、O(α)）は、α の変化に伴って動く導出量として扱う。
- ニュートリノはディラック粒子を仮定する。
- 弱い力：G_F m_e² は y_e だけで決まるので不変。W・Z は電子に対して軽くなる（M_Z/(m_e c²) ∝ √α → 1/√k）が、低エネルギーの現象には効かない。

### 導出量として動くもの
v/E_h（k²）、Λ_au（k²）、G_au（k）、M_W・M_Z/(m_e c²)（1/√k）、m_n − m_p など。詳細は §6。

### 「c を k 倍」との対応
α → α/k と c_au → k·c_au は同じ操作。SI の c → k·c との対応は、「e、ε₀、ħ などを何として固定するか」の約束に依存する（§5）。記事では「原子の物差しと時計で測った光速が k 倍」と言う。

## 5. 方針 1（不採用）と、その理由

### 方針 1 の定義（記録）
**SI で c を k 倍し、他の 30 個の SI 値をすべて固定する。** 真のパラメーターへの翻訳（原子単位系の基底）：

| 原子単位系の基底 | 変化 |
|---|---|
| c | × k |
| α_s | × 1/k |
| G_au | × 1/k⁴（α_G は 1/k⁵） |
| v_au | × k² |
| Λ_au | × k⁴ |
| sin²θ_W、y（12）、λ、混合角（8）、θ_QCD | 不変 |

(α, α_W, α_s, α_G) 型では、α、α_W、α_s が × 1/k、α_G が × 1/k⁵。g、g'、g_s、ε₀、ħ を固定するため、g_s を e と同じ種類の量として一貫して固定すると α_s も α と同じく 1/k になる、という約束の帰結。

### 不採用の理由（2026-11-13 決定）
1. **結果が約束事に左右される。** 結合定数 g、g'、g_s の値は、場の規格化・次元の割り当て（ヘヴィサイド・ローレンツ、ガウス、SI）で書き換えられる。「e を固定」と「e·c^p を固定」は別の世界になる。次元つきの量に c のべき乗をかけて定義し直せば、べき乗で動く任意の族を「c だけが動く」形に書ける。つまり「c だけを変える」には、それだけでは内容がない。意味を持つのは、無次元量がどう動くかである。
2. **α_s → α_s/k は QCD の理論から出てこない。** 標準模型で g_s は無次元（g_s² = 4πα_s）で、c を変えたときに α_s がどう動くかを決める法則はない。方針 1 の結果は「g_s を e と同じ種類の量として SI で固定する」という約束の帰結にすぎない。一方、QCD は電磁気から独立なので、「α だけ動く」ほうが理論に素直な設定である。
3. **結論が計算不能な領域に入る。** k = 1000 では α_s が 1/1000 になり、Λ_QCD が事実上ゼロになる。核子の質量・核力を計算できず、「今の陽子・原子核は存在しない」という定性的な推測しか書けない（文献もない）。
4. **はしごの換算が弱い。** α_s を介した段は、Λ_QCD の α_s 感度（約 ×7.6、概算）と、α_s の基準スケールの選び方に依存し、確度が低い。
5. **方針 2 のほうが山場を少ない仮定で出せる。** 「光速を数 % 変えると炭素ができなくなる」「1000 倍は恒星が光らない」は、α だけを動かす設定で、文献値から直接出る。

### （参考）方針 1 での g_s の扱い
g、g'、g_s は同じ種類の量（α_i = g_i²/(4πε₀ħc) と書ける結合定数）なので、G や Λ と同様に SI の値のまま固定した。e（g）だけを固定して α_s を無次元の数として固定すると、同じ種類の量の扱いが一貫しなくなるため。α_s を不変にする設定（α → α/k、α_s 不変、G・Λ は SI 固定）は別の世界で、方針 2 とも違う（方針 2 は α_G も不変）。

## 7. 記事の構成の考え方
旧方針 3（素朴な導入）は、方針 2 の世界（α だけ 1/k）の日常スケールの帰結にあたるので、別の方針としては扱わず、方針 2 に統合する。以前は「原子核はそのまま」という導入の仮定が方針 1 の帰結と矛盾していたが、方針 2 では矛盾しない（強い力が不変なので、原子核は存在する）。

## 8. はしごの換算式（方針 2）
Δα/α = −Δc/c、すなわち c/c₀ = α₀/α。文献が与える許容幅（α）を、この式で c の幅に直す。「c の許容幅」は「独立な無次元量のうち α だけを動かし、ほかの 26 個を固定したとき」という約束つきの言い方であることを記事で明記する。

## 10. 議論の経緯メモ（出典は sources を参照）
- 無次元量だけが意味を持つ：Duff–Okun–Veneziano「Trialogue on the number of fundamental constants」(JHEP 2002)、Duff hep-th/0208093、Okun の「理論の立方体」(1/c, ħ, G)
- 「c を k 倍」は何を固定するかを決めて初めて無次元量の変化に翻訳される。SI で全固定（方針 1）と原子単位系で全固定（α のみ変化）は別の世界
- 単位系の選択は基底の選び方の一部。基底を変えても 27 個の値の組が指す世界は同じ
- 「c の関数として書ける」ことはどの族でも成り立つ（つまみが 1 つの族なら、すべての量はそのつまみの関数）。そのため、「c だけを変える」だけでは世界が決まらない。決めるのは、どの無次元量がどう動くかである
- 場の再定義・次元の割り当てで g、g'、g_s の値が書き換わるため、方針 1 は曖昧さが残る（§5）
- 2026-11-13：方針 1 を不採用とし、方針 2（α だけが動く世界）に絞る。α_s の代わりに x ≡ Λ_QCD/(m_e c²) を基底に取る
- v を J で固定するか素粒子の質量を kg で固定するかで、重力・Λ の無次元量が変わる。方針 2 は α_G と Λa₀² を直接不変とするので、この選択に依存しない
