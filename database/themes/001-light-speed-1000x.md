## 1. 問いと狙い
「もしも光速が今の 1000 倍だったら、宇宙・太陽系・地球はどうなるか」。
元の動機は「一番近い恒星（アルファ・ケンタウリ、約 4.4 光年）まで 1 日ほどで行ける世界」で、移動時間を 1/1000 にする光速として 1000 倍を選んだ。
記事の核心は、**「光速の値そのものに意味はなく、意味があるのは比だけ」**という事実と、それを認めた上で「光速を変える」とは何を変えることなのかを、読者が追えるように示すこと。

## 2. 基本理論と基本パラメーター

### 基本理論
ニュートリノ質量ありの素粒子標準模型 + 一般相対性理論（宇宙定数つき）。

- ニュートリノがマヨラナ粒子なら位相が 2 つ増える（記事には影響しない）

### 導出量（基本パラメーターではないもの）
- 素粒子の質量：m_f = y_f v/√2、m_W = gv/2、m_Z = m_W/cosθ_W、m_H² = 2λv²（木のレベル）
- 核子（陽子・中性子）の質量：α_s とクォーク質量から決まる。質量の約 99% は QCD の結合エネルギーで、Λ_QCD ∝ μ·exp(−2π/(b₀ α_s(μ))) と α_s に指数関数的に依存する
- フェルミ定数：G_F = 1/(√2 v²)
- 核力、原子核の結合エネルギー、化学結合など

## 3. 真のパラメーター（27 個）
単位は kg、m、s、A の 4 つ。31 個の基本パラメーターのうち 4 方向は単位の取り替えで住人には見えず、残る **27 個の独立な無次元量**の値の組が世界を一意に決める。次元つき定数（c、ħ、G など）の個別の値には物理的意味がない（Duff–Okun–Veneziano の議論。出典は Step 2 で確認）。

27 個の選び方（基底）は一意ではない。単位系を 1 つ選ぶと、その単位での数値の組が自然な基底になる。

### 原子単位系の基底（ħ = m_e = e = 4πε₀ = 1）

数値は目安（CODATA / PDG。出典は Step 2 で確認。結合定数は M_Z でのスケール、クォーク質量は MS-bar）。

注：v と m_H は λ を介して一対一（m_H² = 2λv²）なので、v の代わりに m_H/m_e を基底に使ってもよい。

### (α, α_W, α_s, α_G) 型の基底（ħ = c = m_e = 1）
文献の許容幅との照合に使う。原子単位系との変換：α = 1/c、α_W = 1/(c·sin²θ_W)、α_G = G_au/c、v/(m_e c²) = v_au/c²、Λλ_C² = Λ_au/c²（λ_C = ħ/(m_e c)）。

## 4. 方針 1 の定義（確定）
**SI で c を k 倍し、他の 30 個の SI 値をすべて固定する。** 極端な例として k = 1000 を使う。

### g_s を固定する理由
g、g'、g_s は同じ種類の量（α_i = g_i²/(4πε₀ħc) と書ける結合定数）なので、G や Λ と同様に SI の値のまま固定する。e（g）だけを固定して α_s を無次元の数として固定すると、同じ種類の量の扱いが一貫しない。その結果、α_s も α と同じく 1/k になる。
- 「何を固定するか」は約束事で、物理的に一意ではない（Duff の議論）。方針 1 は「c 以外の次元つき定数をすべて SI で固定する」という一貫したルールを選んだもの。
- α_s は基準エネルギーと繰り込み群に依存する近似である。
- α_s を不変にする設定（α → α/k、α_s 不変、G・Λ は SI 固定）は別の世界で、方針 2 の別候補として残す。

### 真のパラメーターへの翻訳
| 原子単位系の基底 | 変化 | 住人から見た意味 |
|---|---|---|
| c | × k | 原子の時計で測って光が k 倍速い。α が 1/k（電磁気が弱い） |
| α_s | × 1/k | 強い力が弱い |
| G_au | × 1/k⁴ | 原子の力に対して重力が弱い（α_G は 1/k⁵） |
| v_au | × k² | 素粒子の静止エネルギーが原子のエネルギーに対して k² 倍（原子の束縛が相対的にゆるい）。質量比は不変 |
| Λ_au | × k⁴ | 原子の尺度で宇宙定数が大きい（k = 1000 でも 10⁻⁶¹。効かない） |
| sin²θ_W、y（12）、λ、混合角（8）、θ_QCD | 不変 | |

(α, α_W, α_s, α_G) 型で書くと：α、α_W、α_s が × 1/k、α_G が × 1/k⁵。

### 導出の要点
- α = e²/(4πε₀ħc)、α_W、α_s は同じ形なので、g、g'、g_s、ε₀、ħ を固定して c を k 倍すると 3 つとも 1/k。sin²θ_W = α/α_W は不変
- m_e = y_e v/(√2c²) なので、v（J）と y_e を固定すると m_e は kg で 1/k²。原子単位の目盛り（a₀ ∝ 1/m_e、E_h ∝ m_e）が動き、SI で固定した G、v、Λ の原子単位での数値が動く
- G_au = G·m_e·t_au²/a₀³ → (1/k²)(k⁴)/(k⁶) = 1/k⁴。v_au = v/E_h → k²。Λ_au = Λa₀² → k⁴

### 弱い相互作用の扱い
- 低エネルギー（β 崩壊、pp 連鎖、ニュートリノ反応、BBN）の強さを決めるのはフェルミ定数で、G_F = 1/(√2v²)、G_F m_e² = y_e²/4。v と y を固定しているので **不変**
- α_W の 1/k は m_W/m_e → 1/√k で帳消しになる。弱い力の弱まりが見えるのは W 質量に届くエネルギー（100 GeV 級）の現象のみ
- したがって許容幅のはしごに弱い力の段は置かない。文献が G_F や v を動かしている場合（例：weakless universe）は方針 1 には当てはまらない
- 残るのは α、α_s の変化が核子質量差・Q 値を通して β 崩壊に効く間接効果

### 計算不能で「推測」扱いにする項目
- **核子の質量と核力（k = 1000 の場合）**：α_s が 1/1000 になると Λ_QCD が事実上ゼロになり、クォークを閉じ込める力が原子の尺度で消える。信頼できる定量計算がないので、数値を出さず「今の陽子・原子核は存在しない」と定性的な推測として書く
- α_s の数%以内の変化については文献（格子 QCD・有効理論・人間原理の文献）の値を使う（はしごはこれで作る）
- m_p に依存する派生量（チャンドラセカール質量、エディントン限界、21 cm 線など）も同じ扱い

### SI で見えても住人に見えないもの（記事に書かない）
a₀ × k²、原子の時間 t_au × k²、m_e（kg）× 1/k²、M_P（kg）× √k など。これらは目盛りの変化で、無次元の比には現れない。

### 方針 2 の有力候補
「c だけ k 倍、他 26 個の真のパラメーターは不変」= α だけ 1/k の世界。
- 原子単位系では「c の数値だけ 1000 倍」という最も単純な指定
- 元の意図「原子の時計で測ってアルファ・ケンタウリまで 1/1000」に正確に対応
- 強い力と重力は無傷で原子核も星も存在し、変わるのは光の速さ、磁気、放射、相対論的効果、クーロン障壁など

## 7. はしごの換算式（方針 1）
Δα/α = Δα_s/α_s = −Δc/c、Δα_G/α_G = −5Δc/c。
文献が与える許容幅（α、α_s、α_G それぞれ）を、この式で c の幅に直す。「c の許容幅」は「他の SI 値を固定したとき」という約束つきの言い方であることを記事で明記する。

## 9. 議論の経緯メモ（出典は Step 2 で確認する）
- 無次元量だけが意味を持つ：Duff–Okun–Veneziano「Trialogue on the number of fundamental constants」(JHEP 2002)、Duff hep-th/0208093、Okun の「理論の立方体」(1/c, ħ, G)
- 「c を k 倍」は何を固定するかを決めて初めて無次元量の変化に翻訳される。SI で全固定（方針 1）と原子単位系で全固定（α のみ変化）は別の世界
- 単位系の選択は基底の選び方の一部。基底を変えても 27 個の値の組が指す世界は同じ
- v を J で固定するか素粒子の質量を kg で固定するかで、重力・Λ の無次元量が変わる。理論のパラメーターは v なので v 固定を採用
